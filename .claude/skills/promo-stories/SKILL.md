# Промо-ролики по согласованному ТЗ (вертикаль и горизонталь)

ТЗ от главной сессии (идея уже обсуждена с владельцем — не переспрашивай, не меняй смысл, мелочи решай сам).
Формат — из ТЗ: `vertical`, `horizontal` или оба (если ТЗ молчит — оба). Сценарий один на оба формата: НИКОГДА не
делай отдельный сценарий или копию слайдов под горизонталь — раскладку меняет движок.

$ARGUMENTS

Работай из корня checkout (в worktree — из папки worktree). Отвечай по-русски. Ничего не коммить и не публикуй.

## Порядок (экономно)

1. Прочитай образец `scripts/promo/scenarios/save.js` целиком: это готовые экраны Instagram (комментарии, Direct,
   «Запросы»), Telegram (старт бота, сообщения, кнопки), пуш, обложка и финал. Новый сценарий собирай из его кусков.
   `scripts/promo/engine.html` целиком НЕ читай — всё нужное ниже. Классы CSS ищи там grep'ом, только если нужен новый.
2. Создай `scripts/promo/scenarios/<имя>.js` (латиница, коротко: `collections`, `notify`…). Чужой сценарий не правь,
   если ТЗ этого не просит.
3. Лист проверки — ОДНА картинка на формат со всеми ключевыми кадрами (каждая пометка нарисована + конец слайда):
   `node scripts/promo/buildPromo.mjs --scenario <имя> --sheet [--format vertical|horizontal]` → `promo-out/<имя>/sheet.png`
   (вертикаль) и `sheet-horizontal.png`; подписи кадров в консоли. Посмотри нужные. Исправь и пересними только нужное:
   `--sheet --format horizontal --only comment,direct`. Отдельный кадр крупно — `--preview direct:6.5` (только когда по листу не понять).
4. Когда листы чистые — видео: `node scripts/promo/buildPromo.mjs --scenario <имя> [--format …]` (оба формата — 2–5 мин).
5. Удали `promo-out/<имя>/preview-*.png`. Верни отчёт (см. конец).

Перед первым запуском: `NODE_PATH=<основной checkout>/node_modules` (в worktree своих `node_modules` нет; оттуда
`ffmpeg-static`), например `export NODE_PATH="D:/JS/Apps/Practice/SeeLaterTelegram/node_modules"`. Нужен Chrome.

## Чек-лист листа проверки

- Кружок обводит именно цель, стрелка идёт от наклейки к кружку, наклейка не закрывает цель и не вылезает за край (540 px).
- Заголовок и плашка не наезжают на телефон (заголовок — 2 строки; длинное слово уменьшает шрифт само).
- Текст в пузырях не обрезан, пузыри не налезают друг на друга (чаты — в `.flow`).
- Картинки загрузились (постеры, кадр фильма). Пустые плашки постеров = неверный путь TMDB.
- Чужие аккаунты размыты (`fakeAv`, класс `blur`), реальных имён нет.
- Горизонталь: текст слева не заходит под телефон и постеры (правая часть, x от ~590), наклейки слева от телефона не
  перекрывают заголовок (они сами ниже y=250) и друг друга.

## Формат сценария

```js
window.PROMO = {
  films: {main: {media: 'movie', id: 27205}},          // TMDB: название/постер/кадр подтянутся сами (сайт /api/tmdb/media)
  // или явно: {title: '…', poster: '<путь TMDB без / и .jpg>', backdrop: '…'}; явные поля важнее
  coverPosters: [{media: 'tv', id: 1399}, 'zbMASwT2PKpudXBRc2LExAQHASw'],  // 3D-постеры обложки (до 5, по кругу)
  stories: ['cover', 'step1', 'step2'],                  // → story-1-cover.mp4, story-2-step1.mp4 …
  reel: ['cover', 'step1', 'step2', 'end'],              // Reel: подряд со сменой 0.45 с ([] — без Reel)
  slides: () => ({                                       // функция: FILM / FILMS уже заполнены
    cover: {dur: 6.5, html: `…`},
    step1: {dur: 8.5, html: `…`, marks: [ … ]},
    icon: {dur: 1, html: `…`}                            // есть ключ icon → highlight-icon.png 1080×1080
  })
}
```

## Форматы

| | vertical | horizontal |
|---|---|---|
| Для чего | истории (актуальное), Reels Instagram | анимации в Telegram (как обложки /g) |
| Холст → видео | 540×960 → 1080×1920 | 960×640 → 1920×1280 |
| Файлы `promo-out/<имя>/` | `story-<n>-<ключ>.mp4`, `reel.mp4`, `highlight-icon.png`, `sheet.png` | `horizontal/slide-<n>-<ключ>.mp4`, `horizontal/full.mp4`, `sheet-horizontal.png` |
| Звук | тихая дорожка AAC | нет (Telegram покажет как GIF) |
| Раскладка | заголовок сверху, телефон по центру, наклейки под ним | заголовок и текст слева, телефон справа (x 590), наклейки слева от телефона |

Как не дублировать: всё, что зависит от места, — через помощники и классы движка (`cover()`, `stepHead()`, `.phone`),
а не через `style="left/top"`. Если всё же нужна координата или размер — `pick(вертикаль, горизонталь)`, например
`style="top:${pick(432, 330)}px"`. Пометки: `nx/ny/side` — для вертикали; в горизонтали наклейка сама встаёт слева
от телефона на высоте цели; своё место — `h: {nx, ny, side}` в той же пометке. `HORIZONTAL`, `FORMAT`, `CANVAS` — глобальные.

Все координаты в разметке — в пикселях холста; 30 к/с. Длительность: обложка 5–7 с, шаг 8–12 с,
финал 4–5 с. Время в атрибутах — секунды от начала слайда.

### Помощники движка (глобальные)

| Что | Даёт |
|---|---|
| `bg(a, b, c)` | фон: свет (синий, фиолетовый, розовый — яркость 0..1) + зерно. Обложка `bg(.5,.35,.38)`, шаг `bg(.45,.32,.36)` |
| `cover({pill, title: 'A\|B', size: 96, lead, checks: [...], cta, posters: true})` | обложка/финал целиком: постеры, бренд, плашка, заголовок, абзац, выгоды ✓, кнопка; раскладка по формату, время появления само |
| `brand` | логотип «КИНОМАНОВ» (уже есть в `cover()`) |
| `stepHead(n, всего, 'где', 'Строка1\|Строка2', size=46)` | плашка «шаг N из M · где» + объёмный заголовок шага (в горизонтали крупнее) |
| `pick(v, h)` | значение для вертикали / горизонтали |
| `status` | вырез и строка состояния телефона — первым внутри `.screen` (в Telegram — внутри `.tg`) |
| `FILM.title / .poster / .backdrop`, `FILMS.<ключ>` | фильм сценария (URL картинок готовы) |
| `fakeAv(size, hue)` / `myAv(size)` / `logoAv(size)` | размытый чужой аватар / «вы» / логотип Киноманов |
| `heart`, `tgIcon` | сердечко комментария / значок Telegram для `.push` |

### Блоки разметки (классы)

- Обложка/финал — `cover({...})`; классы ниже — только для нестандартного слайда. Обложка/финал вручную: `.pill` (плашка, `<b>` — градиент), `.title` c `data-title="A|B" data-size="96"` (объёмный заголовок),
  `.lead` (абзац, `<b class="grad">`), `.steps > .step.ok > <i>✓</i><span>…</span>` (выгоды), `.cta` (кнопка призыва, `data-pulse="1"`),
  `.scene data-posters` (3D-постеры справа).
- Телефон: `<div class="phone"><div class="screen">${status} … </div></div>` (330×600; место по формату задаёт движок).
- Instagram: `.ig-reel` (кадр фильма сверху, `style="background-image:url(${FILM.backdrop})"`), `.ig-sheet` + `.cmt`
  (комментарий: `.who`, `.txt`, `.meta`; `.cmt.reply` — ответ), `.ig-input .field` (поле ввода), `.ig-head`, `.ig-tabs`
  (Основное/Общее/Запросы с `.cnt`), `.chat-row` (строка чата), `.dm-msg` (входящее в Direct, `white-space: pre-line`),
  `.dm-out` (исходящее), `.dm-input`.
- Telegram: `.tg > .tg-pattern`, `.tg-head` (шапка бота), `.tg-intro` (что умеет бот), `.tg-start` (ЗАПУСТИТЬ),
  `.tg-inputbar`, `.tg-out` (исходящее), `.tg-in` (ответ бота, `<small>` — время), `.tg-btns > div` (инлайн-кнопки).
- Чаты собирай в `<div class="flow" style="top:102px">…</div>` — сообщения встают друг под друга сами.
- `.push` (пуш сверху экрана, `data-anim="drop"`), `.skip` (затемнение «15 декабря / в день премьеры» — переход во времени),
  `.layerScreen` (целый экран внутри телефона — для смены экранов).

### Анимация (атрибуты)

| Атрибут | Что делает |
|---|---|
| `data-in="2.3"` / `data-out="5"` | появление / исчезновение (плавно, лёгкий сдвиг) |
| `data-anim="drop\|pop\|slide"` | вид появления: сверху / пружиной / сбоку (смена экрана) |
| `data-type="текст" data-from="0.5" data-to="1.5" data-clear="2" data-post="#id"` | набор текста в поле; `data-clear` — поле пустеет (отправлено); `data-post` — кнопка отправки ярче, пока есть текст |
| `data-blink="0.3-2"` | мигающий курсор (`<span class="caret">`) |
| `<div class="tap" data-tap="1.8" data-at="#селектор">` | касание пальцем по элементу (кладётся в тот же экран) |
| `data-live="5.1"` | с этой секунды добавляется класс `live` (ссылка становится синей: `.dm-msg a.live`) |

### Пометки «Шаг N» (кружок от руки + стрелка + наклейка)

```js
marks: [{target: '#dmLink', at: 5.4, out: 7.9, pad: [10, 6], note: '<i>Шаг 2</i>Нажмите на ссылку', nx: 30, ny: 690, side: 'up', ok: false, small: false}]
```

- `target` — CSS-селектор внутри слайда (дай цели `id`); `at` — когда рисовать (после её появления!), `out` — убрать (необязательно).
- `pad: [x, y]` — запас кружка вокруг цели; `nx, ny` — левый верхний угол наклейки; `side: 'up'` — цель выше наклейки
  (стрелка вверх), `'down'` — ниже. `ok: true` — зелёный значок (результат), `small: true` — мелкий шрифт.
- Значок в `<i>`: `Шаг 1`, `Шаг 2`… по цепочке; `✓` — результат; `?` / `+` / `🔔` — подсказки.
- Одна главная пометка на момент: следующая появляется после `out` предыдущей или в другой части экрана.
- Вертикаль: наклейки обычно под телефоном (`ny` 690–870) или сбоку от цели; ширина до 270 px — `nx` не больше ~250.
- Горизонталь: обычно ничего не задавай; `h: {nx, ny, side: 'left'|'up'|'down'}` — только если авто-место плохое.

## Правила содержания

- Стиль /g не меняй: палитра, шрифты Montserrat/Inter, стекло, зерно — уже в движке.
- Интерфейсы рисуются, не скриншоты; никаких реальных чужих имён, аватаров и сообщений — только размытые заглушки.
- Тексты бота пиши как в боте на самом деле (если ТЗ не говорит иначе); при сомнении найди фразу в `server/bot/`
  (grep по куску текста) — расхождение упомяни в отчёте.
- Обложка = выгода + призыв («Напишите…», «Нажмите…»); последний слайд Reel — повтор призыва.
- Новый вид экрана (сайт, карточка фильма в боте, подборка) — добавь классы в `<style>` `engine.html` отдельным блоком
  с комментарием, не меняя существующие; упомяни в отчёте.
